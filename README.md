# Hajamir Audio FX

ماژول روت (Magisk / KernelSU / APatch) برای اعمال افکت‌های صوتی واقعی
(اکولایزر، بیس‌بوست، ویرچوالایزر، بلندی صدا) روی کل گوشی، از طریق یه
پنل WebUI ساده با چند پریست آماده.

بر خلاف اکثر ماژول‌های مشابه که فقط `audio_effects.xml` رو دست‌کاری
می‌کنن (که هیچ پارامتر واقعی‌ای ست نمی‌کنه)، این ماژول از یه **اپ همراه**
استفاده می‌کنه که با AudioEffect API واقعی اندروید کار می‌کنه — یعنی
گین EQ، شدت باس/ویرچوالایزر و گین بلندی واقعاً روی صدا اعمال می‌شن.

## پیش‌نیازها

- گوشی روت‌شده با **Magisk**، **KernelSU** یا **APatch**
- اندروید ۸ (API 26) به بالا

## نصب

۱. **ماژول** (`Hajamir_AudioFX_module.zip`) رو از بخش
   [Releases](../../releases) دانلود کن و از داخل مدیر روتت
   (Magisk Manager / KernelSU Manager / APatch) نصبش کن.
۲. **اپ همراه** (`HajamirAudioFX.apk`) رو هم از همون Releases دانلود
   و نصب کن.
۳. اپ همراه رو **یک‌بار** باز کن (فقط برای گرفتن مجوز نوتیفیکیشن —
   بدون این مرحله، سرویس پس‌زمینه‌ای که افکت‌ها رو زنده نگه می‌داره
   استارت نمی‌شه).
۴. گوشی رو ری‌استارت کن.
۵. از WebUI ماژول (داخل مدیر روتت) یه پریست انتخاب کن.

## پریست‌ها

| پریست | توضیح |
|---|---|
| دقیق / نیوترال | بدون تغییر، فقط برای مقایسه |
| موزیک تقویت‌شده | گرم و پرانرژی، برای گوش‌دادن روزمره |
| فیلم / سینمایی | فضای گسترده‌تر + ریورب ملایم |
| وضوح صدا / پادکست | صدای شفاف‌تر، تمرکز روی وضوح گفتار |

## محدودیت‌ها / نکات صادقانه

- این ماژول روی گوشی مدیاتک (Dimensity) تست و کالیبره شده. روی
  چیپست‌های دیگه (اسنپدراگون، اگزینوس) ممکنه مقادیر گین بهینه
  متفاوت باشن — اگه حس کردی خیلی کم یا زیاده، Issue باز کن.
- افکت‌ها به‌صورت global (session 0) روی خروجی صدا اعمال می‌شن —
  یعنی روی همه‌ی اپ‌ها اثر می‌ذاره، نه فقط یه پلیر خاص.
- اپ همراه باید در پس‌زمینه (با یه نوتیفیکیشن کم‌اهمیت) زنده بمونه
  تا افکت‌ها فعال بمونن — این محدودیت خودِ اندرویدیه، نه چیزی که
  بشه دورش زد.
