# Hajamir Audio FX v3 — راهنمای بیلد و نصب

## معماری (خلاصه)
- **اپ همراه** (`HajamirAudioFXApp/`): یه سرویس فورگراند اندرویدی که با
  `AudioEffect` API واقعی (Equalizer/BassBoost/Virtualizer/LoudnessEnhancer/
  DynamicsProcessing) روی خروجی گلوبال صدا (session 0) پارامتر واقعی ست می‌کنه.
- **ماژول مجیسک/KernelSU** (`module_v3/`): فقط یه WebUI برای انتخاب پریسته؛
  دیگه `audio_effects.xml` رو دست نمی‌زنه. با `am broadcast` به اپ می‌گه
  کدوم پریست رو بار کنه.

## گام ۱: بیلد اپ
۱. پوشه‌ی `HajamirAudioFXApp/` رو با Android Studio (نسخه‌ی جدید، AGP 8.5+)
   باز کن — بذار خودش Gradle wrapper رو بسازه (نیاز به اینترنت داره، این
   کاری‌ست که توی sandbox من امکان‌پذیر نبود).
۲. `Build > Generate Signed Bundle/APK` یا فقط Run روی گوشی خودت با یه کلید
   دیباگ.
۳. APK رو نصب کن، یک‌بار بازش کن (فقط برای گرفتن مجوز نوتیفیکیشن روی
   اندروید ۱۳+ لازمه)، بعد می‌تونی ببندیش — سرویس در پس‌زمینه با نوتیفیکیشن
   کم‌اهمیت (min priority) زنده می‌مونه.

## گام ۲: نصب ماژول
پوشه‌ی `module_v3/` رو زیپ کن و از طریق Magisk Manager / KernelSU Manager /
APatch نصبش کن (یا مستقیم از داخل هرکدوم که الان استفاده می‌کنی).

## گام ۳: تست
از WebUI ماژول یه پریست انتخاب کن (مثلاً «موزیک تقویت‌شده»). اگه اپ نصب و
حداقل یک‌بار باز شده باشه، بلافاصله باید تغییر رو بشنوی — چون این بار واقعاً
گین EQ/باس/بلندی ست می‌شه، نه فقط فعال‌سازی یه افکت خالی.

## محدودیت‌های شناخته‌شده (صادقانه)
- **پروفایل EQ فعلی تخمینیه.** مقادیر `eq_shape` توی `Presets.kt` بر اساس
  حدس مهندسی‌ان، نه اندازه‌گیری روی گوشی واقعی — چون من دسترسی به دستگاه یا
  کامپایلر اندروید ندارم. باید روی گوشی خودت گوش بدی و مقادیر `eq_shape` /
  `strength` / `target_gain_mb` رو توی `Presets.kt` فاین‌تیون کنی.
- **DynamicsProcessing به‌عنوان لیمیتر** ساده‌ست (تک‌باند، بدون MBC)؛ کافیه
  جلوی کلیپ آشکار رو بگیره ولی جای یه لیمیتر حرفه‌ای رو نمی‌گیره.
- اگه گوشیت اجازه‌ی افکت روی session 0 رو با محدودیت امنیتی خاصی ببنده
  (بعضی ROM های سفارشی همچین کاری می‌کنن)، ممکنه لازم باشه اپ رو priv-app
  کنی یا مجوز خاص وندور بگیری — چیزی که فقط با تست روی خودِ گوشی مشخص می‌شه.
- `ApplyReceiver` بدون permission قفل، exported=true هست (فقط برای سادگی
  کنترل از شل روت). اگه نگران اپ‌های دیگه‌ای هستی، یه permission سفارشی
  signature-level بهش اضافه کن.
